# Mapa do projeto

## Propósito

A preencher ao iniciar a primeira tarefa.

## Convenções e decisões duráveis

- Não registrar segredos, credenciais ou valores de .env.
- Contexto de trabalho vive neste diretório; a thread é apenas a interface.

## Pontos de entrada

- STATE.md: situação atual e ponte para o próximo chat.
- tasks/active/: tarefa em curso.
- tasks/completed/: histórico concluído.
